# CAM Motos Playwright
Proyecto completo Playwright + TypeScript + Cucumber + POM + POO.

Incluye 8 escenarios: 4 positivos y 4 negativos.

## Instalar
`npm install`

`npx playwright install chromium`

## Ejecutar todos
`npm run test:headed`

## Positivos
`npm run test:headed -- --tags "@positive"`

## Negativos
`npm run test:headed -- --tags "@negative"`
